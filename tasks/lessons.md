# Lessons

- Failure mode: Docker commands used the native `default` context while Colima `default` was running on its profile socket. Detection: `docker context show` returned `default`, while `colima status --profile default` exposed `.colima/default/docker.sock`. Prevention: verify the active context/socket before every Docker operation; use the explicit profile socket when context activation is ambiguous.
- Failure mode: importing the 6.99 GB Ollama image filled host storage and left partial containerd metadata. Detection: host free space fell below 200 MB and Docker reported `input/output error`. Prevention: check host free space before image import; prefer the already-installed native Ollama model or a verified smaller image, and remove only the failed image artifacts.
- Failure mode: a local model sent nullable optional financing filters and routed financing-only questions to the combined vehicle tool. Prevention: make optional filters nullable at the MCP boundary, strip nulls before service calls, and state routing conditions explicitly in the system prompt.
- Failure mode: a compact combined result exposed vehicle and offer prices with the same label, so the model omitted one. Prevention: provide a copy-ready summary and require the vehicle price, offer cash price, monthly payment, and validity disclosure as separate facts.
- Failure mode: semantic vehicle search returned a nearby model for an exact combined request, and a negative answer was mistaken for an availability claim. Prevention: enforce exact model/year selection in the composite tool and make the scorer recognize explicit negative wording.
- Failure mode: comparison payloads exposed omission counts and feature arrays that caused the local model to enumerate data until its output was truncated. Prevention: return comparison prices and a small specification subset only; require source links only when a source exists.
- Failure mode: the local model sent a singular `model`/`modelYear` payload to a two-vehicle comparison tool. Prevention: treat that malformed shape as an empty comparison result so the answer stays truthful and the MCP session remains usable.
- Failure mode: the local model copied a source field name instead of its URL and expanded long equipment lists. Prevention: expose a copy-friendly source URL alias and cap vehicle detail and missing-name arrays at three items.
- Failure mode: the model said offers did not meet a budget without explicitly stating that they exceeded it. Prevention: require the phrases “exceden el presupuesto” or “por encima del presupuesto” when returned prices are over budget.
- Failure mode: financing filters sent at the top level were silently discarded because the tool only accepted a nested `filters` object, allowing unrelated offers into a result. Prevention: accept and normalize both argument layouts, then enforce requested model/year against each returned offer.
- Failure mode: after getting an empty promotion result and populated finance results, the model repeated the finance tool with `offerType: promotion` and described finance plans as promotions. Prevention: instruct it to call each category once, treat empty promotion results as authoritative, and label returned finance plans only as financing.
